# 2026-11-03 - v0.3 refresh

## What changed
- Repo transferred to the `foxreach` GitHub org (`foxreach/cold-md`). Old `concaption/cold-md` URLs 301.
- Plugin packaging fixed. The April `plugin.json` failed `claude plugin validate` with 11 errors
  (skills paths without `./`, invalid `commands`, unknown `environment` field), and the installer
  copied the plugin into `~/.claude/plugins/cold-md`, which Claude Code does not load. Now: a valid
  `plugin.json` (v0.3.0, skills and commands auto-discovered), a root `.claude-plugin/marketplace.json`,
  and an installer that runs `claude plugin marketplace add foxreach/cold-md` and
  `claude plugin install cold-md@cold-md`, falling back to copying skills into `~/.claude`. Older
  installs are moved to `~/.claude/cold-md-backup-<timestamp>/` so skills don't load twice.
- One copy of each skill: `plugin/cold-md/skills/`. The duplicate root `skills/` was removed
  (its copies were identical); `cold-research`, which only existed at the root, moved into the plugin.
- Skills rewritten against the published `foxreach-cli` 0.5.0. Removed calls to commands that do
  not exist (`variants add/update`, `sequences add`, `inbox bulk-update`, `leads create-batch`,
  `analytics workspace-stats/account-stats`, `foxreach openapi`), the `fr_` key prefix (keys are
  `otr_`), and dead URLs (docs.foxreach.io, foxreach.io/audit, /how-it-works).
- New FoxReach capabilities wired in: Lead Finder sourcing, email verification, provider matching
  (`campaigns esp-mix` + `--esp-matching`), a mailbox health guard, `/cold audit` as a real DNS and
  account check.
- `/cold init` writes config v0.3 (`leads`, `sending`, `guards.minAccountHealth`); `--upgrade`
  keeps v0.2 answers. `/cold research` added to the router.
- Site: skill counts fixed (it said ten, six and six in three places), loop updated, new "sending
  layer" section, plugin install commands, `llms.txt`, links moved to foxreach/cold-md and
  www.foxreach.io.
- `examples/foxreach.cold.md`: Identity, Value and objection links updated to the current product;
  dead audit links replaced with the free SPF/DKIM/DMARC checker. The three numeric Proof lines are
  unchanged and were not re-verified in this session.
- `scripts/check.sh` added.
- `spec/cold-md-v0.md`: two dead illustration links (foxreach.io/blog/deliverability, foxreach.io/audit) pointed at example.com. No rule changed.

## Known gap
- FoxReach's public API cannot create A/B variants (they are read-only in `sequences list`).
  cold-send hands the user the variant copy and the app steps. A v1 variants endpoint in FoxReach
  would close the loop.
